# English 90
ロンドンでの仕事に向けて、英語の聞き取りと明瞭な発話を90日間練習する、日本語の個人用PWAです。銀行の会議、データ品質の説明、リスク報告、現地での生活を扱います。学習・録音・復習にChatGPT Plusや有料APIは不要です。

## スマートフォンで始める
1. レビュー済みの変更をmainにマージし、Pagesの配信が完了したら [English 90](https://shinpleas123.github.io/english90/) をSafariまたはChromeで開きます。旧版のURLからも移動できます。
2. iPhoneは共有メニューの「ホーム画面に追加」、Androidはブラウザメニューの「アプリをインストール」または「ホーム画面に追加」を選びます。「設定」にオフライン保存完了が出るまで一度オンラインで開きます。
3. 開始日の初期値は2026年11月28日です。「設定」で変更できます。開始前もDay 1を試せます。「今日の学習」で60分または15分を選び、「学習を始める」を押します。
4. 精聴は、原稿を隠して聞く、初回答を記録、該当箇所を確認、再聴の順です。シャドーイングはチャンクを選んで反復、重ね読み、原稿を隠して録音します。90日分の英国英語MP3は同梱済みで、端末に英国音声がなくても再生できます。自分のお手本ファイルも読み込めます。端末の声を使う場合は、OSの読み上げ設定に英国英語のオフライン音声を追加してください。
5. 初日は発音課題の「固定原稿」と「初見比較原稿」を別々に録音します。「技能別に自己評価を記録」では、聞き返した箇所を手掛かりに、確認できた項目だけ記録します。7日ごととDay 30・60・90も同じ条件で測ります。即興課題の録音はCamblyでの聞き返しと合わせて確認できます。
6. 完了したら達成条件にチェックし、「完了して記録」を押します。忙しい日は「途中まで記録」も使えます。15分版は精聴3分、発音6分、即興5分、振り返り1分です。90日後も教材を再訪でき、復習日は続きます。

## 発音を採点する場合
自動採点を使う本人がAzure PortalでSpeechリソースを作り、価格レベル **Free F0** とリージョンを確認します。S0は課金対象になり得ます。Azureに登録しなくても録音比較と自己評価ができます。利用条件と技術検証は [Speechの設計](docs/SPEECH.md) にまとめています。

「設定」に地域識別子とキーを入力し、F0の確認にチェックを入れます。個人端末ではキーの保持を選べます。キーはGitHubとバックアップには入りません。共用端末での利用後は「キーを消去」を選んでください。

「発音診断」で録音するか、端末が復号できる音声ファイルを読み込みます（1件64 MB・10分まで）。「Azureで区間を採点」で開始・終了秒と実際に読んだ英文を確認し、「区間を送信して採点」を押します。選択した音声と英文をMicrosoftに送ります。30秒を超える録音は、続く区間と対応文を選んで個別に採点できます。端末の採点・認識予約は月240分まで。失敗時も予約を保持します。

採点結果にはAPIが返した単語・音素レベルの値を表示します。en-GBで名称を特定できない音素には番号を付けます。低い単語スコアや読み落としは翌日の復習候補になります。舌・唇・声の説明は練習の手掛かりです。Web Audioのピッチとポーズは録音からの推定、録音長は実測です。語数換算速度は読み落としや言い直しに影響されます。

## データを持ち出す・戻す
「設定 → バックアップを保存」で音声を含むJSONをダウンロードします。復元時はそのファイルを選びます。端末を変更するとき、ブラウザデータを削除する前、空き容量が少ないときはバックアップしてください。同一オリジンに残っている旧版の学習時間・採点履歴・開始日を初回に取り込みます。旧版のJSONも復元できます。

## 開発・公開
公開資産はリポジトリのルートにあります。教材MP3の出典・CC BY-SA 4.0の表示・再生成手順は [音声クレジット](docs/AUDIO.md) にあります。実行時はビルド・npm・PCが不要です。開発時には Node と Playwright を使います。

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
npm run build:offline
```

インストール済みChromeを使う場合は環境変数 `BROWSER_CHANNEL=chrome`。WebKit検証は `npx playwright install webkit` の後に `ENGINE=webkit node tests/pwa.browser.mjs`。オフライン対象を編集したら必ず `npm run build:offline` で `sw.js` を再生成します。開発時は親ディレクトリで `python -m http.server 8000` を起動し、配下のリポジトリURLを開きます。

本番の配信元はGitHubのSettings → Pages → Deploy from a branch → main / (root) を想定します。マージ後にPagesのデプロイ成功とルートURLの応答を確認してください。[Pagesの配信元](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

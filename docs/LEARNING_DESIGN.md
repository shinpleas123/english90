# English 90 の学習設計

対象は、英語で銀行業務を経験し、ロンドンでの会議や質疑応答に備える学習者。目標は、聞き手が数字・条件・結論を一度で捉えられる発話と、相手の発言から同じ情報を取り出せる聴解である。英国音声を練習の参照にする。特定の話者の声の高さや地域アクセントへの一致は達成条件に含めない。

## 研究から決めた練習方法

| 一次研究と対象 | 観察されたこと | English 90 での使い方と限界 |
| --- | --- | --- |
| Derwing, Munro & Wiebe (1998)。成人ESL学習者の12週間の授業。音読と即興の語りを別々に評定。 | 音読文では分節音を中心とする群と広く話し方を扱う群の両方で聞きやすさが向上。即興では後者で聞きやすさと流暢さが向上した。 | 単語を修正したら、意味のまとまりと焦点の置き方を変え、原稿を閉じて同僚向けに言い直す。固定文のスコアだけで会議での上達を判断できない。[論文](https://doi.org/10.1111/0023-8333.00047) |
| Vandergrift & Tafaghodtari (2010)。フランス語を学ぶ106人が同じ音源を同じ回数聞いた学期間の比較。 | 予測、理解の確認、聞き違いの分析を取り入れた群が、開始時の差を調整した最終理解テストで優位だった。 | 原稿を隠して要点を取る → 内容問題に答える → 不確かな箇所を書き取る → 原稿を確かめる → 該当箇所を再聴する。書き取りと意味理解は別に記録する。教室での仏語の結果をこの利用者の伸び幅に換算できない。[論文](https://doi.org/10.1111/j.1467-9922.2009.00559.x) |
| Hamada (2016)。日本の大学での英語学習者43人、9回のシャドーイング授業。 | 低群・中群とも音の知覚に改善があった。高校水準の内容理解問題では低群だけが改善した。 | チャンクで聞こえた連結・弱形を一つ選び、重ね読み、台本なしの追唱、録音比較へ進む。追唱の速さは意味理解を保証しないため、精聴と要約も組み合わせる。中上級の社会人に20分が最適という研究ではない。[論文](https://doi.org/10.1177/1362168815597504) |
| Lively, Logan & Pisoni (1993)。日本語母語話者の英語 /r/ と /l/ の同定実験。 | 話者や音環境の違いが新しい例への般化に影響した。練習した語や声での成功だけでは般化が分からない。 | 対立を二語で確かめたら、語句と別の文に移る。Camblyでは台本を見せずに聞き手が受け取った語を確認できる。一つの合成音声での練習と研究の多話者訓練は条件が異なる。[論文全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3509365/) |
| Karpicke & Roediger (2008)。外国語語彙の学習と遅延再生の実験。Cepeda et al. (2008)。事実の学習・復習・遅延テスト。 | 一度正答した後も記憶から取り出す練習が後日の再生に役立った。保持に有利な学習間隔はテストまでの期間で変わった。 | 翌日以降に先に発話してから見本を聞く。思い出せた項目の間隔を延ばし、難しい項目は早く戻す。復習日数は運用上の初期値で、発音技能について研究が確定した最適値ではない。[想起の研究](https://doi.org/10.1126/science.1152408)・[間隔の研究](https://doi.org/10.1111/j.1467-9280.2008.02209.x) |

## 60分で何を確かめるか

| 練習 | 配分 | その場で確かめること |
| --- | ---: | --- |
| 精聴 | 10分 | 結論、数字、例外のどこを聞き違えたか。初回の内容問題と、原稿確認後の練習を区別する。 |
| 発音 | 15分 | その日の一語を単独で言い、語句と短い業務文に戻す。前後の録音は同じ距離・速度で聞く。 |
| シャドーイング | 20分 | 見本だけを聞く → 一チャンクに区切る → 見本と重ねて読む → 少し遅れて台本を隠して追う。耳で比較したい箇所だけ再録する。 |
| 即興 | 10分 | 原稿を閉じ、同僚の質問に結論と根拠を返す。意味上の焦点を置いた語が聞き手に残るかを確かめる。 |
| 振り返り | 5分 | 「良かった」「難しかった」で終えず、聞き違いまたは聞き返された語を一つ選び、翌回の確認対象にする。 |

15分の日は素材を一部分に絞る。全体を急いでこなすより、一つの意味の聞き分けと一つの発話の再試行を完結させる。短いメニューの達成と、60分メニューの未完了を区別できるようにする。

## 評価の読み方

- **固定原稿**はDay 1に利用者指定の英文を一度音読する。定点観測では同じ原稿と録音条件を選ぶ。原稿への慣れも結果に反映される。
- **初見原稿**は定期評価で初めて開き、練習前の一回を残す。別原稿の難度は厳密には等化されていない。点数差だけでなく、どの語・条件・数字を聞き手に伝えられたかを確認する。
- **即興**は、自作したリスク状況の説明、異議の提示、質疑応答に移す。Camblyでは、台本を見せる前に聞き手に「結論、数値、次の行動」を言い返してもらうと、通じた箇所を具体的に残せる。
- **時間と達成率**は学習を継続できたかを表す。**発音採点**は対象録音に対するサービスの出力、**ポーズと相対音高**は録音から得た参考値、**聞きやすさ**は人が実際に聞いて行う評価として読む。マイク、環境雑音、原稿、速度、短縮練習の条件が違えば数値も変わる。
- **弱点候補**は根拠と一緒に扱う。例えば *growth* の単語スコア低下は、その語を聞き直す理由になる。/θ/ の置換が発生したとの結論には別の証拠がいる。音素が特定できないときは語全体を再練習し、後日の別文でも聞き返されるか確かめる。未測定にゼロを入れたり、独自指標をVERSANTへ換算したりしない。

## 英国英語の見本と教材

日別のニュース調・業務場面の英文と発音ドリルの例文は本アプリ用の創作である。事例の金額・日付・業務判断は練習用。最新の金融ニュースや実務方針としては使用しない。日々の音源は端末の英国英語音声を利用できる。話者名・速度を揃えて比較し、辞書リンクでは **UK** の人声も確認できる。辞書音声をアプリには収録しない。[Cambridge Dictionary の発音案内](https://dictionary.cambridge.org/pronunciation/)

各語のドリルには口・舌・声の使い方、対象の音を含む最小対、当該語を使った短い句と文、再録手順を収める。最小対は必ずしも見出し語を含まない。例えば *Thursday* は *thin / sin* で語頭を対照させてから曜日の練習に戻る。*households* は辞書の単数形 *household* と有声子音 /d/ 後の複数語尾 /z/ に基づく。英国の発音には幅があり、非R音の見本を採用しても地域差を矯正対象にはしない。[IPAの調音表](https://www.internationalphoneticassociation.org/IPAcharts/IPA_charts_TI/IPA_charts_TI.html)・[growth](https://dictionary.cambridge.org/pronunciation/english/growth)・[world](https://dictionary.cambridge.org/pronunciation/english/world)・[work](https://dictionary.cambridge.org/pronunciation/english/work)・[Thursday](https://dictionary.cambridge.org/pronunciation/english/thursday)・[household](https://dictionary.cambridge.org/pronunciation/english/household)

# 技術設計
公開GitHubリポジトリのPagesプロジェクトサイト。HTML、CSS、標準ESモジュール、IndexedDB、Service Workerを使う。インストール後はPC・Plus・生成AI APIがなくても教材にアクセスできる。パスはプロジェクト相対。ビルドや常駐サーバーは不要。[GitHub Pages の用途と制限](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)

## 音声経路
マイクまたはファイルを端末で保存。Web Audioで復号・音響計測。お手本には英国音声を選び、利用可能な声がない場合は明示する。Azureは個人がF0リソースを用意して明示的に実行するオプション。30秒を超える一続きの録音は保存でき、採点時に再生区間と対応原稿を選ぶ。採点されていない区間に点数を付けない。
## 安全性
ユーザー入力やAPI応答は表示前にエスケープする。アプリスクリプトは同一オリジン、外部送信先はSpeechサービスに限定する。キーを持つ本人の端末からの直接送信はサーバー運用が不要。同一オリジンのコードからキーにアクセスできるため、共有端末では保存しない。専用トークン中継サーバーは認証・不正利用対策・運用が必要で、個人のF0構成には導入しない。

## 端末内のデータと更新
教材・英国MP3・チャンク境界は同梱する。tools/build-sw.mjs が配布ファイルの内容ハッシュを生成し、版ごとのキャッシュをインストールする。更新は設定画面から適用し、IndexedDBを保持する。範囲リクエストもキャッシュ済みMP3から返す。教材音声の出典は [AUDIO.md](AUDIO.md)。

lib/store.mjs は設定、学習イベント、音声メタデータ、Blobの4ストアを使う。録音の作成・削除、バックアップからの統合は複数ストアで原子的に行う。旧版のローカル履歴を移行して元データを保持する。キーと利用量台帳はJSONの対象外。タイマーはタブごとに保存し、他画面やバックグラウンドで一時停止する。

lib/derive.mjs は単語の精度80未満・読み落とし・自己申告を復習対象にする。翌日から始め、改善確認で3、7、14、30日へ延長する。数値は運用上の設定。近い日の精聴初回答が低い場合は速度と開始チャンクを調整する。固定原稿と初見・再読を区別し、同じ原稿・入力方法・課題・ロケール・評価方式の結果を比較する。録音距離や実機の機種は本人が揃える。

Web Audioで復号し、PCM16 WAVには独立したデコーダも用意した。40ms窓のRMSと自己相関から相対音高を推定し、有声部の中央値を0半音とする。200ms以上の内部の低音量区間を求める。これらを強勢の正誤やアクセントの点数に変換しない。原稿語数換算の速度は全文を読んだ場合の推定。音節境界や自由発話の語数は未測定。

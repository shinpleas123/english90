# 開発と公開の順序
1. main c40cc82 の6ファイルと公開HTTPを確認。プロジェクトルートに入口を追加。既存利用者の履歴とURLを引き継ぐ。
2. 端末内の録音、任意のF0音声採点、単語に対応した矯正、履歴、バックアップ、更新可能なPWAを実装。
3. 90日教材、60分と15分、初見・固定評価、翌日以降の復習、精聴・録音比較を統合。
4. 実ブラウザで保存・復元・録音・通信失敗・モバイル幅・オフラインを検証。レビュー用PRを作成。マージ後にPagesのルートと実機を確認する。

## 既存実装の調査
2026-11-24、HTTPS HEADはルート404、旧階層200。リポジトリのルートに入口がなかった。app.jsではdayから週を計算して12原稿から選ぶ。短縮ボタンは発音タイマーのみ。精聴はBBCトップを開く。録音はメモリBlob。JSON出力は録音を含まず復元経路もない。30秒超は送信前に中断する。キーはsessionStorage。sw.jsはキャッシュ優先で同一originの他アプリのキャッシュまで削除し得る。実API成功を示す記録はなかった。
再利用対象は指定の定点原稿、開始日、en-GB指定、16 kHz PCMの方針、旧履歴のデータ形式。UIと状態管理は再実装する。旧アプリの公開URLからは新版へ移れるようにする。

## 実装後の状態
Phase 1〜3の変更をPR #1に保存。Phase 4ではモバイル幅、録音、区間採点、復元、PWAの更新を検証し、端末音声の有無にかかわらず精聴できるよう英国英語の教材音声を収録した。本番公開と実機・実キーでの確認事項は [引き継ぎ](HANDOVER.md) にまとめた。

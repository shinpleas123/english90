# 検証記録
2026-11-24、Windows上のNode v25.9.0、Playwright 1.58.2、Chrome。静的サーバーの /english90/ 配下にPRのファイルを配置して実行。GitHub Pagesの配信については下記の別欄を参照。

| 項目 | 実行・結果 |
| --- | --- |
| 自動テスト | npm test は13件すべて成功。90日・180プラン、16評価日、原稿と設問の独自性、調音ガイド、復習日、同条件の比較、実PCMからの音高と内部休止、API系9件。 |
| レイアウト | Chromeで320 / 390 / 430 / 768 CSS px幅のホームに横スクロールなし。390pxでホーム・採点詳細・シャドーイング画面をキャプチャ。 |
| 学習導線 | ブラウザで15分コース4課題を確認し、精聴を開始、原稿切替、設問・書き取りを提出、完了として保存。初見評価の初回表示と再読、シャドーイングの原稿切替を操作。 |
| 音声 | Chromeの仮想マイクからMediaRecorderで実際にBlobを生成。端末上のデコード・保存・再生を検証。マイク拒否とファイル読込も確認。実際の人の発話は使用していない。 |
| Speechの区間処理 | 生成した31秒の44.1kHzステレオWAVを実ブラウザで復号し、指定2秒だけを16kHzモノラルPCMに変換。HTTP本文の長さと対応原稿を検証。 |
| 接続と採点結果 | japaneastの実エンドポイントへのCORS OPTIONSでHTTP 204。認証付きPOSTはモックで429・成功応答を検証。モック値はサービスの有効性や英語力向上の証拠に使っていない。 |
| 無料枠 | 同時に開いた2タブで上限直前の送信を競合させ、一方のみ予約できることを確認。旧版利用秒、エラー時の予約保持、再読込を確認。 |
| 永続保存 | 学習結果、採点、復習、音声が再読込後も保持。録音を含むJSONをダウンロード、録音削除、復元後に再生。キーがエクスポートに含まれないこと、非対応の版を拒否することを確認。 |
| オフライン・更新 | ChromeのService Workerがインストールされた後に通信を遮断し、再起動・90日教材を読み込み。旧版履歴の移行後に更新版ワーカーを配信し、設定から適用。新しいHTMLと録音履歴を確認し、オフラインで再起動。 |
| 本番のルート | 変更前にHTTPS HEADで /english90/ は404、旧階層は200を実測。開発ブランチのルートはローカルHTTPで動作。mainへのマージは所有者判断のため、本番ルートの新版HTTP 200は未検証。 |
| 認証・実機 | 実際のAzureキーでのPOST、Apple/Androidの実マイク、実機への追加とアイコン起動、OS別のM4A/MP3デコーダ、Azureの実利用量は未検証。本人確認手順は [引き継ぎ](HANDOVER.md)。 |
| 学習効果 | 90日試験は未実施。スコア改善やVERSANT換算値を掲載しない。 |

## 再現
[利用手順](../README.md) の開発手順を使用。tests/app.browser.mjs はUIを通した操作、tests/pwa.browser.mjs は配信バージョン差し替え、tests/speech.browser.mjs は範囲変換と利用量の競合を対象にする。通常のテストでAzureへの認証付き送信は発生しない。
